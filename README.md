A one-line resignation letter for make.fun's "The One-Line Exit" bounty: a proper resignation frame ("I hereby resign, effective immediately...") whose punchline is that after five years the office vending machine knows the writer's name and their manager still doesn't. One line, 121 characters, and the whole letter is the joke. The program writes exactly that line to `/output/entry.txt` and checks the bounty gate itself (one line, 1–140 characters) before writing.

## Run it

```sh
python3 main.py
```

This writes the resignation letter to `/output/entry.txt`.
